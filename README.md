# 01-ts-basics

Домашня робота з основ TypeScript, створена за допомогою Vite.
Кожне завдання розміщене в окремому файлі `src/task-1.ts`–`src/task-8.ts`.
Усі завдання підключені через `src/main.ts` до `index.html`.

## Запуск

```sh
npm install
npm run dev
```

Відкрий адресу з термінала. Результати виконання доступні в консолі браузера
(інструменти розробника → Console). Завдання 6 лише повертає значення;
завдання 7 виводить повідомлення через секунду, а завдання 8 потребує інтернету.

## Перевірка та форматування

```sh
npm run build
npm run format
npm run format:check
```

Для здачі надай посилання на репозиторій із вихідними файлами.
За умовою завдання після завантаження змін на GitHub зачекай 5 хвилин перед здачею.
